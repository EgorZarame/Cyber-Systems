# ai-service

Помощник, который подсказывает игроку, что не так в его программе из блоков. Работает только с
уровнями, где дрон ходит по полю (сейчас 1.1, 1.2 и 2.2).

Как работает:

1. Симулятор прогоняет программу игрока по полю с теми же правилами, что в игре.
2. Небольшая нейросеть (scikit-learn, `MLPClassifier`) по признакам попытки определяет тип ошибки:
   упёрся в препятствие, не доехал, проехал мимо финиша, поехал не туда и так далее.
   Настоящих данных игроков пока нет, поэтому сеть обучается при старте на сгенерированных попытках
   (случайные программы и испорченные правильные), это занимает пару секунд.
3. Поиск в ширину находит кратчайший путь к финишу из точки, где остановился дрон.
4. Чем больше попыток у игрока на уровне, тем подробнее подсказка: сначала только в чём ошибка,
   потом маршрут из текущей точки, потом длина полного маршрута.

Запуск (Python 3.11+):

```
pip install -r requirements.txt
INTERNAL_TOKEN=... uvicorn app.main:app --port 8083
```

Интерактивное описание методов откроется на `/docs`.

| Метод | Путь | Что делает |
|---|---|---|
| GET | /health | статус и точность модели на отложенной выборке |
| POST | /internal/hint | `{levelId, program, attempts}` возвращает диагноз и подсказку |

`program`: список блоков `"move"`, `"left"`, `"right"` или циклов `{"type": "loop", "count": 3, "body": ["move"]}`.
Если задан `INTERNAL_TOKEN`, нужен заголовок `X-Internal-Token`. Браузер ходит не сюда, а в game-service (`POST /api/hint`).

Тесты: `pip install -r requirements-dev.txt && pytest --cov=app`.
