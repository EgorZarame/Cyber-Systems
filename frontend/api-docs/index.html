КиберСистемс: описание API

Четыре сервиса общаются по HTTP и JSON. Раскрой метод, чтобы увидеть пример запроса и ответа.
Игровой сервисСервис авторизацииИИ-сервисСервис данных

Ошибки Java-сервисов приходят в виде {"error":"код","message":"пояснение"}, а ИИ-сервис отвечает в формате FastAPI: {"detail":"…"}.

Токен игрока получают в сервисе авторизации и передают в заголовке Authorization: Bearer …. Он живёт 12 часов.

Служебный токен X-Internal-Token нужен для обращений между сервисами и задаётся переменной окружения INTERNAL_TOKEN.

Игровой сервис (game-service) :8080

Уровни, профиль игрока, попытки и подсказки. Именно с ним работает браузер.

Все методы, кроме GET /api/levels, требуют заголовок Authorization: Bearer <токен>, который выдаёт сервис авторизации.

GET/api/levelsСписок всех уровней

Доступ: нет

Ответ

[{"id":"1.1","type":"DRONES","difficulty":"EASY","orderIndex":1,"title":"Первые шаги"}, ...]
GET/api/profileПрофиль текущего игрока

Доступ: Bearer JWT

Ответ

{"id":"…","nickname":"Стажер","currentLevelId":"1.1"}

Ошибки

  • 401 нет или неверный токен
  • 404 профиль не найден
POST/api/profile/progressОтметить уровень пройденным и задать текущий уровень

Доступ: Bearer JWT

Тело запроса

{"levelId":"1.2"}

Ответ

{"id":"…","nickname":"Стажер","currentLevelId":"1.2"}

Ошибки

  • 400 пустой или неизвестный уровень
  • 401 нет токена
POST/api/profile/nicknameСменить ник

Доступ: Bearer JWT

Тело запроса

{"nickname":"Нео"}

Ответ

{"id":"…","nickname":"Нео","currentLevelId":"1.1"}

Ошибки

  • 400 пустой ник или длиннее 50 символов
GET/api/profile/next-levelСледующий уровень по правилам прохождения

Доступ: Bearer JWT

Ответ

{"id":"1.2","type":"DRONES",…}  или 204, если игра пройдена
GET/api/profile/completed-levelsИдентификаторы пройденных уровней

Доступ: Bearer JWT

Ответ

["1.1","1.2"]
POST/api/attemptsЗаписать попытку игрока

Доступ: Bearer JWT

Тело запроса

{"levelId":"1.1","program":"[\"move\",\"move\"]","success":false}

Ответ

201 без тела

Ошибки

  • 400 нет levelId или program
POST/api/hintПодсказка от ИИ-помощника по текущей программе

Доступ: Bearer JWT

Тело запроса

{"levelId":"1.2","program":["move","left",{"type":"loop","count":3,"body":["move"]}]}

Ответ

{"levelId":"1.2","supported":true,"verdict":"blocked","confidence":1.0,"hint":"Дрон упёрся в препятствие…","nextSteps":["повернуть налево","двигаться вперёд"],"detailLevel":2,"stats":{…}}

Ошибки

  • 400 уровень не найден или программа длиннее 100 блоков
  • 502 ИИ-сервис недоступен

Сервис авторизации (auth-service) :8081

Регистрация, вход и выдача JWT. Пароли хранятся только в виде BCrypt-хэша в data-service.

Методы открытые, кроме /api/auth/me.

POST/api/auth/registerСоздать аккаунт и сразу войти

Доступ: нет

Тело запроса

{"login":"player1","password":"secret123"}

Ответ

{"token":"eyJ…","userId":"…","login":"player1"}  (201)

Ошибки

  • 400 логин короче 3 или пароль короче 6 символов
  • 409 логин уже занят
POST/api/auth/loginВойти по логину и паролю

Доступ: нет

Тело запроса

{"login":"player1","password":"secret123"}

Ответ

{"token":"eyJ…","userId":"…","login":"player1"}

Ошибки

  • 401 неверный логин или пароль (ответ одинаковый в обоих случаях)
GET/api/auth/meКто я: проверка токена

Доступ: Bearer JWT

Ответ

{"userId":"…","login":"player1"}

Ошибки

  • 401 токен неверный или просрочен

ИИ-сервис (ai-service) :8083

Определяет тип ошибки в программе игрока нейросетью и строит подсказку. Браузер к нему напрямую не ходит.

Нужен заголовок X-Internal-Token (если задан INTERNAL_TOKEN). Только /health и /docs открыты.

GET/healthСостояние и точность модели на отложенной выборке

Доступ: нет

Ответ

{"status":"ok","levels":["1.1","1.2","2.2"],"modelAccuracy":0.999}
POST/internal/hintДиагноз и подсказка по программе

Доступ: X-Internal-Token

Тело запроса

{"levelId":"1.2","program":["move","move"],"attempts":3}

Ответ

{"verdict":"stopped_short","confidence":0.98,"hint":"…","nextSteps":[…],"detailLevel":2,"supported":true}

Ошибки

  • 401 неверный служебный токен (тело {"detail": …})
  • 422 неверный формат запроса

Сервис данных (data-service) :8082

Единственный, кто работает с PostgreSQL. Служебный: используют только auth-service и game-service.

Нужен заголовок X-Internal-Token (если задан INTERNAL_TOKEN).

Ответ

Ошибки

  • 409 логин занят
